TasksHub is a cross-platform mobile application developed using React Native and Expo as part of the Mobile Application Development Practical 07, demonstrating persistent local storage via AsyncStorage, local device notifications using expo-notifications, image picking from the gallery with expo-image-picker, and hybrid file-based navigation (Tabs + Stack) implemented through Expo Router. The application features a robust tech stack comprising React Native Expo SDK, Expo Router, AsyncStorage, expo-notifications, expo-image-picker, and MaterialCommunityIcons (@expo/vector-icons). Its structured project architecture consists of an app directory containing root layouts (_layout.tsx), task addition views (add-task.tsx), and tab navigation files including _layout.tsx, index.tsx, and profile.tsx, alongside an Output_Screens folder designated for execution screenshots, a package.json file, and this comprehensive README documentation.
